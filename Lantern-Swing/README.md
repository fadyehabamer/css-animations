# Lantern-Swing

> Ramadan fanous swinging on its chain, pure CSS

### [View Live Demo](https://fadyehabamer.github.io/css-animations/Lantern-Swing/)

## Overview

A fanous (Ramadan lantern) made only of CSS shapes: `clip-path` for the cap, body and base, arched windows with a warm radial gradient, and a small flame in the middle. The whole lantern swings from the top of its chain while the windows and flame flicker and a soft glow pulses behind it.

## Built With

**Languages:** HTML · CSS

## Techniques Demonstrated

- `clip-path` polygons for the lantern parts
- `transform-origin` at the top of the chain for the pendulum swing
- Layered keyframe animations for glow, flicker and flame
- A `--u` unit custom property to scale the whole drawing
- `prefers-reduced-motion` fallback that keeps the lantern still with a slow glow
